# FitPilot 电子健身私教｜使用说明

## 你拿到的是什么

这是一个可以在电脑和手机浏览器中运行的健身私教 Agent 初版，已包含完整核心流程：

1. 建立个人训练档案
2. 自动生成每周训练计划
3. 查看 AI 数字教练动作示范、目标肌群与关键提示
4. 逐组记录重量和次数
5. 自动开始组间休息计时
6. 记录 RPE、目标肌群感受、疼痛与代偿
7. 保存训练总结和历史
8. 向训练 Agent 提问
9. 安装为桌面/手机 Web App

没有 OpenAI API Key 时，除生成式回答外的所有核心功能都能正常工作，Agent 会使用内置的本地规则回答。

## 1. 启动项目

在终端进入项目目录：

```bash
cd "/Users/joycelyn-gao/Documents/Codex/2026-10-15/2-02-https-v-douyin-com"
npm install
npm run dev
```

本机浏览器打开：

<http://127.0.0.1:3000>

同一 Wi-Fi 下的其他电脑或手机打开：

<http://192.168.1.110:3000>

共享访问时，运行项目的 Mac 和终端窗口必须保持开启。若以后局域网地址变化，可在 Mac 终端运行：

```bash
ipconfig getifaddr en0
```

然后把得到的地址替换进 `http://局域网地址:3000`。访问时浏览器显示“Not Secure”是本地 HTTP 开发服务的正常提示，不影响同一局域网内使用。

建议使用 Node.js 22 或更高版本。

## 2. 第一次使用

1. 填写称呼、年龄、身高、体重。
2. 选择训练目标、经验、每周训练天数和单次训练时间。
3. 只勾选真实可用的器械。
4. 如实填写旧伤或需要避开的部位。
5. 阅读并勾选安全确认，点击“生成我的训练计划”。

计划生成后，选择一个训练日并点击“开始”。计划页的 14 个核心动作分别绑定独立的数字真人示范图；动作名称、器械类型和展示姿势一一对应，不再按动作大类复用同一张图片。每完成一组就点击大号绿色按钮；休息计时会按绝对结束时间保存，即使刷新页面也会继续计算剩余时间。

计划、训练、训练总结和 Agent 页面顶部都有“返回”和“返回主菜单”。训练中离开页面不会结束或清空训练；回到训练台后点击“继续训练”即可恢复到原进度。

完成一个动作的全部组数后，填写主观反馈。若选择任何疼痛等级，界面会明确提示停止当前动作；危险症状和疼痛规则优先于加重逻辑。

## 3. 启用 AI 教练（可选）

复制环境变量模板：

```bash
cp .env.example .env.local
```

打开 `.env.local`，填写：

```dotenv
OPENAI_API_KEY=你的_OpenAI_API_Key
OPENAI_MODEL=gpt-4o-mini
```

保存后重新运行 `npm run dev`。

API Key 只在服务端使用，不会写入浏览器。模型请求失败、超时或格式不正确时，系统会自动回退到本地教练回答。涉及疼痛、胸痛、呼吸困难、眩晕等内容时，会跳过模型并直接执行确定性的本地安全规则。

启用 AI 模式后，服务端会把你的当前问题、精简后的训练档案与计划，以及最近 3 次训练的时间和总结发送给 OpenAI，以生成相关建议。请不要在问题中填写不希望交给模型处理的敏感信息。

## 4. 安装到手机或桌面

- iPhone/iPad Safari：点击分享按钮 →“添加到主屏幕”。
- Android Chrome：打开浏览器菜单 →“安装应用”或“添加到主屏幕”。
- 桌面 Chrome/Edge：地址栏出现安装图标时点击安装。

安装后会以独立窗口打开，训练数据仍保存在对应浏览器/安装实例的本地存储中。

## 5. 清除演示数据

在训练台页面底部点击“重置本机数据”，确认后会清除当前浏览器中的档案、计划和训练记录，并回到初始建档页。

## 7. 当前版本边界

- 数据默认只在本机浏览器中，不含账号和云同步。
- 不包含摄像头姿态识别、支付、社交和医疗诊断。
- 动作示意用于训练提示，不能替代现场教练或医疗专业意见。
- 若训练中出现胸部不适、异常气短、眩晕、晕厥或明显疼痛，请立即停止训练并寻求合适的专业帮助。
